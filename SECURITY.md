# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of
`pdfjs-viewer-element`. Older releases are not supported.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Earlier releases | No |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through a
[GitHub security advisory](https://github.com/alekswebnet/pdfjs-viewer-element/security/advisories/new).
Do not open a public issue for a vulnerability.

If private reporting through GitHub is unavailable, email
alekswebnet@gmail.com with the subject `Security: pdfjs-viewer-element`.

Include the affected version, a clear description of the issue, steps to
reproduce it, and any proof-of-concept or suggested remediation. Reports will
be reviewed and acknowledged after triage. Please allow time for a fix to be
developed and released before publicly disclosing the vulnerability.
